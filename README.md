> [!WARNING]

> ### АНТИВИРУСЫ И WinDivert
>
> Антивирус может отреагировать на WinDivert.  
> WinDivert перехватывает и фильтрует трафик, поэтому необходим для работы zapret.
> Этот инструмент могут применять как безопасные, так и вредоносные программы, однако сам WinDivert вирусом не является.
>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)**
>
> Часть антивирусов считает файлы WinDivert потенциально опасными или относит их к хакерским инструментам. В результате файл удаляется и попадает в карантин. Название обнаружения при этом обычно содержит `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте каталог zapret в исключения антивируса либо выключите обнаружение PUA — потенциально нежелательных приложений. Например, в Kaspersky есть настройка "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы хорошо понимаете настройки исключений, предпочтительнее исключить нужную папку. Если нет — рекомендуется отключить обнаружение PUA.

## ⚙️Использование

1. Сначала включите безопасный DNS (Secure DNS).
    * В Chrome активируйте "Использовать безопасный DNS" и выберите поставщика, отличного от "Поставщика по умолчанию".
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", нажмите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query` — провайдер Cloudflare может быть заблокирован.
    * В Windows 11 Secure DNS можно включить непосредственно в параметрах системы — [инструкция](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот вариант рекомендуется.
    * Владельцам роутеров Keenetic нужно включить в настройках опцию "Транзит запросов". При отключённой опции Secure DNS на компьютере может работать некорректно.

2. Получите zip/rar-архив с [последнего релиза](https://github.com/Radianiovalue/zapret-discord-youtube/releases/latest).

3. Откройте свойства архива и установите флажок "Разблокировать". Для архивов, открытых через 7-Zip или PeaZip, этот шаг не требуется.

4. Распакуйте архив в каталог, путь к которому не содержит кириллицу и специальные символы.

5. Запустите подходящий файл.
    * Для поиска рабочей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`.
    * Чтобы включить автозапуск, выберите **`service.bat`** -> `Install Service` -> нужную стратегию.

## ℹ️Кратко о файлах

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии.

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества факторов, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдёте подходящую именно для вас**.

- [**`service.bat`**](./service.bat) — автозапуск и дополнительные операции:
  - <ins>**`Install Service`** — добавление выбранной стратегии в автозапуск через services.msc.</ins>
  - **`Remove Services`** — удаление стратегии и WinDivert из служб.
  - **`Check Status`** — просмотр состояния обхода и служб, включая стратегию автозапуска и WinDivert.
  - **`Game Filter`** — включение или отключение обхода для игр и прочих сервисов, использующих UDP и TCP на портах выше 1023.  
  **После изменения этого параметра стратегию необходимо перезапустить.**  
  Текущее состояние отображается в скобках: включено или выключено.
  - **`IPSet Filter`** — изменение режима обхода для сервисов, перечисленных в `ipset-all.txt`.  
  Опция пригодится при проверке ресурса, который без zapret не открывается.  
  В скобках показывается состояние:
    - `none` — ни один IP не проходит проверку;
    - `loaded` — IP сравниваются со списком;
    - `any` — под фильтр попадает любой IP.  
  - **`Auto-Update Check`** — включение или отключение автоматического поиска обновлений.
  - **`Replace active fakes`** — замена выбранного активного фейка на другой из каталога `bin`.
  - **`Update IPSet List`** — загрузка актуального `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** — обновление hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>.
  - **`Check for Updates`** — ручная проверка обновлений.
  - **`Run Diagnostics`** — поиск распространённых причин неисправности zapret.  
  В завершение можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает после внезапного прекращения работы приложения.
  - **`Run Tests`** — запуск проверки стратегий:
    - `Standard tests` — тестирование сайтов из `utils/targets.txt`;
    - `DPI checkers` — проверка DPI у разных провайдеров, включая Cloudflare и Amazon.

## ☑️Распространённые вопросы и проблемы

### После запуска `general*` ничего не происходит

Если стратегия запущена отдельным bat-файлом, а не через service, должен появиться процесс winws.exe, видимый на панели задач.  
Если этого не случилось, обратитесь к [#522](https://github.com/Radianiovalue/zapret-discord-youtube/issues/522).

### Не подходит ни одна стратегия
- Запустите командную строку с правами администратора.
- Выполните в ней команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер.

### Не открывается Telegram в браузере

В **`service.bat`** выберите **`Update hosts file`**. Если файл hosts окажется устаревшим, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открывшегося блокнота.
  - Откройте файл `hosts` в созданной папке текстовым редактором, запущенным от имени администратора.
  - Вставьте скопированный текст в конец `hosts` либо замените ранее добавленные аналогичные строки.
  - Сохраните файл и проверьте подключение ещё раз. Если результата нет, убедитесь, что изменения действительно сохранились.

#### Работоспособность не гарантируется. При отсутствии результата используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/Radianiovalue/tg-ws-proxy) или любым публичным прокси.

### Обход не запускается или перестал работать

> [!IMPORTANT]
> **Стратегии способны со временем терять работоспособность.**
> Иногда вариант работает некоторое время, а затем перестаёт из-за обнаружения используемого метода.
> В проекте собрано много стратегий обхода. Если готовые варианты не помогают, можно создать собственную, взяв одну из них за основу и изменив параметры.
> Описание параметров находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте наличие ошибок через `service.bat` -> `Run Diagnostics`.

- Убедитесь, что нужный адрес указан в списках доменов или IP.

- Проверьте другие варианты, включая **`ALT`**, **`FAKE`** и прочие стратегии.

- Выполните полную переустановку по инструкции ниже.

- Дополнительная информация: [#765](https://github.com/Radianiovalue/zapret-discord-youtube/issues/765).

### Как полностью переустановить или обновить проект?
- Сохраните добавленные вами ресурсы и данные.
- Перезагрузите устройство.
- Откройте `service.bat` -> `Remove Services`.
- Запустите `service.bat` -> `Run Diagnostics`; если будут найдены ошибки, исправьте их, затем в конце выберите Y.
- Удалите старый каталог zapret.
- Скачайте свежую версию [со страницы релизов](https://github.com/Radianiovalue/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`).
- Нажмите ПКМ по архиву, откройте свойства и, если справа внизу есть пункт разблокировки, установите его, затем нажмите «Применить» и «ОК».
- Распакуйте архив в новый каталог в корне диска; путь не должен содержать пробелы и специальные символы.
- Запускайте разные скрипты `general` и проверяйте интернет-ресурсы. Если выбранный вариант не работает, закройте программу через значок замка на панели задач и попробуйте следующую стратегию.
- После выбора рабочего варианта включите автозапуск: `service.bat` -> `Install Service` -> нужная стратегия.

### Игра или приложение не работает при включённом zapret

- В `service.bat` проверьте, что `Game Filter` имеет состояние **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит обнаруживает WinDivert

- Инструкция находится здесь: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### В Windows 7 требуется цифровая подпись драйвера WinDivert

- Замените `WinDivert.dll` и `WinDivert64.sys` в [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё числится среди служб

1. В командной строке Windows узнайте имя службы. Открыть командную строку можно через Win+R и `cmd`:

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, что настроен [Secure DNS](#%EF%B8%8Fиспользование).
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Переберите остальные стратегии, особенно если раньше выбранная работала.
- См. также [#251](https://github.com/Radianiovalue/zapret-discord-youtube/discussions/251).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включён [Secure DNS](#%EF%B8%8Fиспользование).
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить её.
- В `service.bat` откройте `Run Diagnostics` и выполните очистку кэша Discord.
- После очистки проверьте приложение Discord.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно временно пользоваться ей.
- Если Discord не запускается и в браузере, повторно проверьте все стратегии: YouTube и Discord могут работать на разных вариантах.
- Дополнительные сведения: [#252](https://github.com/Radianiovalue/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/Radianiovalue/tg-ws-proxy).
- Также можно использовать бесплатные MTProto-прокси из интернета.

### Не запускаются игры

Игр много, поэтому проверить и исправить каждую из них невозможно.

Попробуйте универсальную последовательность:
- через `service.bat` обновите ipset и включите `Game Filter`;
- если это не помогло, дополнительно активируйте `ipset any`.

Учтите: при включённом `ipset any` могут перестать открываться многие сайты. Не оставляйте этот режим включённым постоянно. Лучше определить все IP-адреса, используемые игрой, и добавить их в `ipset-all.txt`.

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/Radianiovalue/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Не нашли подходящего ответа

- Опишите проблему [здесь](https://github.com/Radianiovalue/zapret-discord-youtube/issues).

## 🗒️Добавление адресов других ресурсов

Расширить список адресов для обхода можно через следующие файлы:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически;
- **`list-exclude-user.txt`** — домены-исключения, например когда IP-сеть присутствует в `ipset-all.txt`, но конкретный домен из неё фильтровать не нужно;
- **`ipset-all.txt`** — IP-адреса и подсети;
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, которые нужно исключить.
  - Файлы **`*-user.txt`** автоматически создаются при первом запуске `zapret` или `service.bat`.
